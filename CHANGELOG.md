# Changelog

Version numbers track the upstream release this fork is built from, so
`2.12.0` here corresponds to upstream `2.12.0`.

## 2.12.0

First release as `applooma_rtc_core`.

- Renamed from the upstream package, including its library entry points and the
  CocoaPods and Swift Package Manager package names.
- Removed the upstream example, tests and build tooling from the published
  archive.
- No functional changes to media transport. See NOTICE for attribution.
