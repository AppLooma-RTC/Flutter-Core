# applooma_rtc_core

Media transport core for the [AppLooma RTC](https://applooma.dev) Flutter SDK.

**You almost certainly want [`applooma_rtc`](https://pub.dev/packages/applooma_rtc)
instead.** This package is the low-level transport layer it is built on. It is
published separately because Dart resolves dependencies by package, not by
bundle, and it carries no stable public API of its own.

- Documentation — https://docs.applooma.dev/sdk/flutter
- Issues — https://github.com/apploomadev/Flutter-Core/issues
- Support — support@applooma.dev
